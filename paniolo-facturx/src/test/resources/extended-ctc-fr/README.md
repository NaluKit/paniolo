# EXTENDED-CTC-FR examples

The XML files in this folder are the official CII examples of the French profile EXTENDED-CTC-FR,
taken unmodified from the release
[v1.4.0.04 of FNFE-MPE France_RFE](https://github.com/fnfempe/France_RFE/releases/tag/v1.4.0.04)
(`FNFE_RFE_INVOICE/Z.example/TEST/CII/EXTENDED-CTC-FR`), licensed under the Apache License,
Version 2.0. They are used as test data only.
