# Order-X examples

The XML examples of the Order-X 1.0 release package of FNFE-MPE and FeRD (2021-04-13, folder
`05-ORDER-X EXAMPLES/_ORDER-x_EXAMPLES_<profile>/_XML for direct access`), unmodified, including
their UTF-8 byte order mark. The terms of use of the package apply the Apache License 2.0 to the
technical artifacts of Order-X. They are used by `OfficialOrderXRulesTest` only and are not part of
any published artifact.
