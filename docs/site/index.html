Send, receive & renderJava
Paniolo paniolo = Paniolo.create();

// model -> XRechnung UBL, official KoSIT rules packaged
String xml = paniolo.toXml(invoice, InvoiceSyntax.UBL);
ValidationResult result = paniolo.validate(xml);

// UBL, CII, ZUGFeRD 1.0 or a Factur-X PDF
Invoice received = paniolo.read(Files.readAllBytes(path));

// rendered page + embedded XML (paniolo-pdf-layout)
byte[] pdf = paniolo.toFacturX(invoice, FacturXProfile.EN16931);

Exact calculation

Line amounts, allowances and charges, VAT breakdown, and totals are calculated with BigDecimal, so every written document is consistent.

Automatic detection

One call validates or reads whatever arrives: UBL or CII, XML or PDF, with the profile taken from BT-24 and the PDF metadata.

Findings you can trace

Every finding carries its original rule ID, severity, XPath, and stage, and goes into an XML report with an XSD for archiving.

Checks beyond the rules

Optional calculation check, rule statistics for audits, and an acceptance policy that names the warnings your process must not accept.

PDFs without a PDF

Render DIN 5008 invoices, orders, and delivery notes in German, English, or French, with logo and own fonts, as PDF/A-3b.

Shown in the browser

The dependency-free web component <paniolo-viewer> displays XML and PDF documents in any web application.
