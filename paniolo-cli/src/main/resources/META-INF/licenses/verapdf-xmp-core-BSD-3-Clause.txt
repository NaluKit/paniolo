veraPDF XMP Library Core (org.verapdf:verapdf-xmp-core)
========================================================

This JAR bundles the unmodified classes of veraPDF XMP Library Core in
package org.verapdf.xmp and its subpackages. The component is based on the
Adobe XMP Toolkit for Java 5.1.3 (XMPCore) and is distributed under the
BSD 3-Clause License, as declared by its upstream POM and by the LICENSE.txt
of its source module. Its source files carry these copyright notices:

    except the veraPDF additions listed below

    the veraPDF additions impl.VeraPDFExtensionSchemaDefinition,
    impl.VeraPDFExtensionSchemaProperty, impl.VeraPDFExtensionSchemasContainer,
    impl.VeraPDFMeta, impl.VeraPDFXMPNode, containers.StaticXmpCoreContainers
    and tools.SecureXML (the latter with portions derived from the Adobe
