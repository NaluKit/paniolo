Paniolo CLI: third-party licensing and source availability
========================================================

Paniolo code is licensed under Apache License 2.0. Bundled dependencies
and validation resources retain their respective licenses. See the merged
META-INF/NOTICE, META-INF/LICENSE* and META-INF/licenses/ for their terms.
The rules archives also retain notices and license texts within them.

Build maintenance: verify this list against the runtime dependency tree
when changing dependencies. Saxon and veraPDF versions are filled in by
Maven, including the Saxon source link; the transitive Rhino, StAX-Utils,
JAXB and Activation versions and the XMP copyright holders must be
reviewed when upgrading. The
LicenseNoticesIT test checks the packaged *-all.jar for these notices.
