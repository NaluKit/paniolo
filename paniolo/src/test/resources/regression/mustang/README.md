# Regression files for Mustang issues

Small invoices that reproduce problems reported for Mustangproject, created with Paniolo for the
analysis of the open Mustang issues on 31 October 2026. They are kept unchanged.

| File | Mustang issue | Case |
|------|---------------|------|
| `base.xml` | #1316 | Valid control invoice (CII) without allowance |
| `percent-no-base-CII.xml`, `percent-no-base-UBL.xml` | #1316, #640 | Document allowance with percentage 10 and no base amount |
| `repeated-accounts.xml` | #279, #1248 | Factur-X EXTENDED with two buyer accounting accounts (ACC1, ACC2) |
