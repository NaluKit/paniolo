# Test XML

| File                     | Origin                                                                                                                                       |
|--------------------------|----------------------------------------------------------------------------------------------------------------------------------------------|
| `erechnung-ok-01.xml`    | CII invoice produced with Mustangproject (comment `generated by: mustangproject.org`) from test data of a test tenant ("Test Mandant 03 - 01"); example IBAN |
| `erechnung-not-ok-01.xml`| The same invoice with one VAT rate (`RateApplicablePercent`) commented out by hand, so that validation reports errors                         |
| `not-an-erechnung.xml`   | A generic `browserconfig.xml` (web site tile configuration), used as well-formed XML that is not an invoice                                   |

The documents are test material of the project; the output of Mustangproject is not subject to
the Mustang license. Seller, buyer, and bank data are test data, not data of real customers.
