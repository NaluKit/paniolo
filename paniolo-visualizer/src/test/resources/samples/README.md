# Samples

Documents for the tests and the demo page of the visualizer. Most are written with Paniolo itself.
`invoice-extended-sub-lines.xml` is the official EXTENDED-CTC-FR example
`UC12_F202600025_SOUS-LIGNE` of [FNFE-MPE France_RFE v1.4.0.04](https://github.com/fnfempe/France_RFE/releases/tag/v1.4.0.04),
licensed under the Apache License, Version 2.0, taken unmodified.

`invoice-extended-display.xml` carries the EXTENDED information the views show (further parties,
logistics service charges, financial adjustments, product and reference details); it is the invoice of
`ExtendedDisplayLayoutTest` in `paniolo-facturx`, written with Paniolo.
